# Number Guessing Game

Este proyecto es un juego clásico de adivinar el número ejecutado desde la terminal. Mi implementación se enfoca en ofrecer una experiencia de usuario fluida mediante menús interactivos y una lógica de juego dinámica que ajusta el desafío según la dificultad seleccionada.

## ✨ Características principales

- **Niveles de Dificultad**: Tres niveles preestablecidos (Fácil, Medio, Difícil) que determinan el número máximo de intentos permitidos.
- **Feedback Dinámico**: Pistas inteligentes que indican si el número secreto es mayor o menor al ingresado por el usuario.
- **Sistema de Puntuación**: Registro de récords personales basados en el tiempo de ejecución y eficiencia en los intentos.
- **Interacción**: Sistema robusto de validación de entradas para asegurar una partida sin errores técnicos.

## ⚡ Instalación

Puedes instalar y probar el juego directamente desde mi repositorio:

```sh
pip install git+https://github.com/6GinT0/Number-Guessing-Game.git
```

## 🚀 Uso

Simplemente ejecuta el comando global una vez instalado:

```bash
$ number-guessing-game
```
